About replay & speed

Replay follows the order you paint, erase, and repaint. Imported drawings, patterns, and resized grids reveal in grid order. Shorter loops play faster in the preview and all animation exports. Color cycle rotates all 16 inks; Rainbow wave sends color bands diagonally across cells; Warm glow cycles through warm shades. These effects keep the background fixed. Playback never changes your drawing.

Data formats

C64/mixed text stores glyphs, dimensions and character set in a labeled hex grid, not PETSCII bytes. Legacy-only text uses Unicode approximations. Text and screen codes omit colors; export color RAM separately (one index 0–15 per cell, row-major). JSON keeps all colors. Binary is row-major screen codes without dimensions or charset; legacy shapes cannot be converted safely.
