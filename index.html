About replay & speed

Replay follows the order you paint, erase, and repaint. Imported drawings, patterns, and resized grids reveal in grid order. Loop duration sets the total timeline. Movement and Color cycles per loop set independent rates: 1×, 2×, 4×, 8×, or 16×. Every cycle finishes at the loop boundary. These settings apply to preview and every animation export. Color cycle rotates all 16 inks; Rainbow wave changes cell colors without moving glyphs. Its direction and waveform are independent of movement. Warm glow cycles through warm shades. Choose movement and color animation independently; both share one loop duration. Movement carries cell colors with the glyphs, then the color effect changes the ink. Rainbow bands follow destination positions. Wavelength sets the spacing: 50% matches the original waves; 100% is twice as long. Movement and color lengths are independent of height and cycles. These effects keep the background fixed. Playback never changes your drawing.

Data formats

Glyph IDs select one of 512 source atlas slots across both C64 character sets. Text uses PETSCII-GLYPHS with three-digit hexadecimal IDs. Include colors in text adds cell inks and the shared background; imports detect either format automatically. Binary uses two bytes per cell, little-endian, with FFFF for empty. These are not native screen-code or PETSCII bytes. Color RAM stores one ink index per cell. JSON keeps the complete artwork.
